# Wirevo v0.94.0 — browser CMake and CYW43 ROM data

The browser CMake path now evaluates bounded function scopes/arguments/PARENT_SCOPE, if/elseif/else, NOT/AND/OR, numeric/string comparisons and DEFINED, foreach IN ITEMS/LISTS, option, list APPEND and GLOBAL include guards. configure_file creates virtual C/header outputs with @ONLY/COPYONLY and cmakedefine/cmakedefine01. Pico board/platform variables are initialized from the selected board/architecture. Generated files reach the actual Clang WASM compiler; .h.in inputs survive file/ZIP workflows. CMake USB/UART stdio settings now configure the SDK runtime. The new Projects example exercises function/condition/template/library/USB stdout end to end.

This remains a bounded browser evaluator and compatibility SDK, not the full upstream CMake executable or complete Pico SDK. Host processes, FetchContent, arbitrary custom build commands, PIO source generation and all upstream libraries are not implemented. Full upstream builds remain available through the existing local build/import path. Generated output is capped at 100 KB, evaluation at 10000 operations / 32 levels, and foreach at 256 elements; unsupported syntax fails explicitly.

CYW43439 now accepts a locally supplied 640 KiB ROM data image at backplane 0x00800000..0x0089ffff, read-only through GPIO gSPI. The model copies the bytes, reports CRC32/source, preserves ROM across power/reset and rejects writes. No ROM is bundled or uploaded to a server; the bytes are session-only and are not embedded into JSON. CRC32 is an integrity indicator, not proof of authenticity. The CPU/firmware/radio execution flags stay false.

The inspected upstream Nexmon directory contains RAM firmware and definitions, not rom.bin. Its dump_rom application requires physical hardware. Sources: https://github.com/seemoo-lab/pico-nexmon and https://github.com/seemoo-lab/nexmon/tree/master/firmwares/bcm43439a0/7_95_49_2271bb6 . Actual CYW43 ROM CPU execution, 802.11 MAC/PHY and original radio firmware remain unfinished. Loading ROM data does not complete these engines.

Only newly added checks were run: 20 cases covering browser CMake/USB/circuit execution on eight boards and all twelve C board/architecture profiles, template ZIP/scopes/guards and ROM-data GPIO reads on four W boards plus memory protection. ROM-data cases use a labeled synthetic byte fixture and do not claim validation against a real CYW43 ROM. Prior test suites were not run.
