# 0.101.0 — sade Pico SDK paneli

SDK paneli ilk düzenine benzer derleme yöntemi seçimi, bölüm başlıkları ve alt alta tam genişlikte dosya alanlarıyla yeniden düzenlendi. Kurulum ve kullanım adımları artık panelin altında tıklayınca aşağı doğru açılır. ZIP/klasör paket desteği ve tarayıcı derlemesi korunur; port veya yardımcı uygulama geri eklenmez.

Yalnız değişen arayüz doğrulandı: yöntem değişimi, alan görünürlüğü, açılır adımlar, örnek paket seçimi. Eski testler çalıştırılmadı.
