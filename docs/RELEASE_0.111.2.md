# Wirevo 0.111.2 — SuperMini görseli

Yalnız Pro Micro nRF52840 / SuperMini gövdesi kullanıcının sağladığı siyah kart fotoğrafıyla değiştirildi. Fotoğraf değiştirilmeden SVG içinde kart bölgesi gösterilir; ayrı header parçaları görünmez. Görüntü oranı korunur; pad ve LED konumları fotoğrafa hizalandı. Pin kimlikleri, elektriksel davranış ve diğer kartların görselleri korundu. Yalnız bu görsel ve pin kimlikleri denetlendi; eski testler çalıştırılmadı.
