# CircuitForge 0.50 · STM32 ADC tarama / sürekli ölçüm

Dokuz STM32 kartında1..16regular rank, continuous, sağ/sol alignment; F401/F41112/10/8/6bit resolution. F1dizi-sonuEOC ve F4EOCS/OVR farklılığı, IRQ18 ve software restart. Yeni C API ve pin penceresi ayarları; projeye özel sıra/mode/formatCinit veJSON/ZIP. SPI/USART ve0.49ARM ITSTATE düzeltmesi korunur. Tarayıcıdaki üç kanallı ADC kabulünde bulunan STMIA T1 R7 decoder hatası M3/M4F kaynak motorunda düzeltildi.
