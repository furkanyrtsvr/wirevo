# nRF52840 0.114.0 — yeni NimBLE doğrulaması

Eski testler çalıştırılmadı. GitHub çalışma kopyasında `npm run build` ve yalnız `node --test tests/nrf52-nimble114.test.mjs` çalıştırıldı: **11/11 başarılı**, yaklaşık 37.7 saniye (tek yerel ölçüm).

- SuperMini, nice!nano v2, XIAO ve Sense: gerçek C NimBLE host/merkezi firmware, GPIO tact, korunan ATT read reddi, iki tarafta aynı Numeric Comparison kodu, açık onay, şifreli GATT/CCCD, A/B/Shift/release, Caps output/kart LED’i, oturum RAM bond yeniden bağlantısı.
- Onayı reddetme: kimlik doğrulama ve klavye raporu yok.
- 7 bayt anahtar ve SC biti olmayan istek reddi.
- TinyCrypt C AES-CCM çerçevesi bağımsız OpenSSL ile açıldı; MIC bozma ve eski şifreli çerçeve tekrarında bağlantı kesildi.
- Şifreli bağlantıyı plaintext ACL’ye düşürme reddi.
- Yeni wide REV/REV16/REVSH işlemleri gerçek ARM firmware içinde doğrulandı.
- Yerel tarayıcı: Yeni proje → NimBLE örneği → Derle → Çalıştır → BLE bağlan. İki kod 440013/440013; kullanıcı onayı sonrası doğrulanmış/AES-CCM durumuna geçti. A basma/bırakma ve Caps Lock ardından B, alıcıda `aB` üretti. Browser console error görülmedi. Son arayüz yalnız kullanılan BLE bölümünü gösterir; SDK kütüphanesi ihtiyaca göre ayrı modül yüklenir.

Bu sonuç sanal HCI portunun doğrulamasıdır; fiziksel RF, Nordic RADIO/CCM donanımı, SoftDevice veya Zephyr/ZMK kabulü değildir. RAM bond reset/sayfa yenilemede silinir. Kütüphane içi kaynak debug yoktur; kullanıcı C debug altyapısı korunur.
